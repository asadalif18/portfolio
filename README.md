# Asad Ali — AI/ML, Computer Vision & LLM Engineer Portfolio

A production-grade personal portfolio showcasing my work in **Computer Vision**, **LLM Agents**, **MCP Servers**, **RAG Pipelines**, **Voice AI (STT/TTS)**, and **Edge AI** — built with vanilla HTML/CSS/JS and a live 3D neural network rendered with Three.js.

**Live site:** [![Live](https://img.shields.io/badge/live-asadalif18.github.io-22d3ee?style=flat-square)](https://asadalif18.github.io)

## ✨ Highlights

- **Live 3D neural network** — revolving WebGL visualization with pulsing nodes and animated synaptic connections
- **Floating tech chunks** — glassmorphic mini-windows drifting through the hero (`YOLOv12`, `LangGraph`, `MCP`, `Whisper`, etc.)
- **Fully responsive** — mobile-first design with animated hamburger nav
- **Zero build step** — pure HTML/CSS/JS, loads directly from GitHub Pages
- **Accessible & SEO-ready** — semantic markup, Open Graph meta, descriptive alt text
